# 前輩記憶館同步工具 V1.0
用途：從輪迴檔案館的「完整備份（.gab）」離線拆解，不讀 Firebase、不發送網路請求、不修改正史。

1. 電腦檔案館先核對本機所有世界觀及交接稿，再匯出完整 .gab。
2. 使用已登入同一 Google 帳號的 Drive 電腦版，在其 My Drive 中定位「Gal AI・歷代前輩記憶館」；八個資料夾已在雲端建立。不得指向公開／共用磁碟或既有 GalArchive 開發中轉站。
3. Node.js 22（標準函式庫，無 npm 安裝需求）。先執行：
   node predecessor-library.js "C:\path\backup.gab" "G:\我的雲端硬碟\Gal AI・歷代前輩記憶館" --dry-run
4. 確認輸出數量、世界觀歸屬及目的地，將同一指令改為 --apply。等待 Google Drive 電腦版同步，再從雲端核對最新匯出索引、原始備份大小及分卷／附件。
5. 重複同一備份會按 SHA-256 重用原檔；新備份僅增加變更版本及新索引，舊檔不刪除。請勿直接編輯自動生成的檔案；手動整理放在共用守則、茶話會、個人檔案獨立文件。
6. 前輩先讀「00・全館索引與共用守則／最新匯出索引.md」，依索引路徑定位世界觀、輪迴與交接稿。個人索引只使用原始記載的管理者及撰寫者，不猜身分。
限制：.gab 只包含已收進檔案館的內容；未歸檔的茶話會及 GPT 聊天需另行保存。原始 JSON 保留所有欄位及附圖；分卷按原始訊息邊界，事件簿保留全部狀態，只有原備份明確指定 storyPlacement 的已接事件插入閱讀順序，未定位者另標記，不推測。這不是網站的完整自動事件排序算法，也不是正式原生掃描驗收。沒有排程或直接雲端 API 寫入，必須由本機取得真實 .gab 並完成 Drive 同步。禁止將私人輸出提交 GitHub。

安全注意：指定單一電腦寫入此資料庫，工具會拒絕同一電腦同時匯出；不要在兩台裝置同時寫入。僅自動索引由工具更新，人工資料不覆蓋。
